# Behemoth Chronicle

Persistent fictional chronicle of Behemoth's life approximately one year after the events of *The Master and Margarita*.

The repository is the durable memory of the project. Public posts live in `posts/`; causal state and unresolved threads live in `state/`; stable project canon lives in `canon/`.

Telegram publication is intentionally outside this repository workflow and may be added as a separate automation later.
